{% comment %} Renders a person's name, linked to their homepage if _data/authors.yml knows one. Usage: {% include author-link.html name="Loic Landrieu" %} Resolution is by full name rather than by an explicit key stored alongside the person. A duplicated key silently goes stale the moment a name is edited — which is exactly what happened when "Loïc" was normalised to "Loic" and this one link quietly disappeared. Matching on the name means adding someone to authors.yml links them everywhere at once. {% endcomment %} {% assign _name = include.name %} {% assign _url = nil %} {% for _pair in site.data.authors %} {% assign _a = _pair[1] %} {% capture _full %}{{ _a.first_name }} {{ _a.last_name }}{% endcapture %} {% assign _full = _full | strip %} {% if _full == _name %}{% assign _url = _a.url %}{% break %}{% endif %} {% endfor %} {%- if _url -%}{{ _name }}{%- else -%}{{ _name }}{%- endif -%}
