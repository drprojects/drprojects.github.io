torch-graph-components holds algorithms for fast graph connected components and graph partitioning, fully implemented in PyTorch with GPU parallelization in mind. In particular, this project contains the graph components and graph partitioning algorithms introduced in [EZ-SP](https://louisgeist.github.io/ez-sp).
