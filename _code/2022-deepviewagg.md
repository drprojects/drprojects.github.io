Official implementation for [DeepViewAgg](https://drprojects.github.io/deepviewagg). This codebase holds tools for multimodal learning on 2D images 🖼️ and 3D point clouds ☁️️. In particular, we developed an efficient and scalable framework for learning to densely map and aggregate multi-view image features to point clouds.
